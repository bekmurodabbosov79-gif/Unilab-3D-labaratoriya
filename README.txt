# UniLab 3D — Cyberpunk Virtual Lab

## Ishga tushirish
1. Node.js o'rnatilgan bo'lsin.
2. Terminalda shu papkaga kiring.
3. `npm install`
4. `npm start`
5. Brauzerda http://localhost:3000 ni oching.

Three.js kutubxonasi CDN orqali olinadi, shu sababli 3D sahnalar ishlashi uchun internet kerak.
Bu boshlang'ich demo: Om qonuni hisob-kitobi brauzerda bajariladi; natijalar serverga saqlanmaydi.
Mavjud fayllaringizni o'chirmang. Avval ushbu loyihani alohida papkada sinab ko'ring.
